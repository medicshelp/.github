# Contributing to Medics Help

Thank you for your interest in Medics Help. We are a small team in an early stage, and we welcome careful feedback.

## Where to write

| Repository | What it is for | How to reach us |
|---|---|---|
| [responsible-ai](https://github.com/medicshelp/responsible-ai) | How our AI is designed and the rules we follow | Open an issue, or email [info@medics.help](mailto:info@medics.help) |
| [medics-website](https://github.com/medicshelp/medics-website) | The website [medics.help](https://medics.help) | Open an issue for typos, broken links or display problems |
| [brand-assets](https://github.com/medicshelp/brand-assets) | Logos, colours and images | Email [info@medics.help](mailto:info@medics.help) (issues are turned off) |
| [.github](https://github.com/medicshelp/.github) | Organisation profile and these files | Email [info@medics.help](mailto:info@medics.help) (issues are turned off) |

For partnerships, press or questions about the product, email [info@medics.help](mailto:info@medics.help).

## Issues

- Search existing issues first, so we avoid duplicates.
- One topic per issue, with a clear title.
- Describe what you expected, what happened, and how to reproduce it (browser, device, language version of the site).
- Write in English if you can. German and Ukrainian are fine too.
- **Never include real personal or medical data.** See the [code of conduct](CODE_OF_CONDUCT.md).

## Pull requests

Small pull requests are welcome, for example fixing a typo, a broken link or an accessibility issue. For bigger changes, please open an issue first so we can agree on the approach.

Please note that the website and brand assets are **All rights reserved**. By opening a pull request you agree that Medics Help may use your contribution in its projects.

## Security

Never report security issues in public. See [SECURITY.md](SECURITY.md).
